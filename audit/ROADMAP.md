# ROADMAP

Этот файл хранит только утверждённый план реализации. Он отвечает на вопрос
«что и в каком порядке должно быть сделано», но не доказывает фактическую готовность.
Развёрнутое обоснование фаз, оценки, риски и матрица покрытия — в
[`docs/plan-tz/roadmap.md`](../docs/plan-tz/roadmap.md).

## Метаданные

- Статус: `approved`
- Версия: `1`
- Утверждено: `2026-09-07`
- Владелец: `ИП Спиркин И.Р.`
- Источник ТЗ: `Приложение № 1 к Договору №4063 от 10.08.2026` — [`docs/plan-tz/tz.md`](../docs/plan-tz/tz.md)
- Последнее изменение scope: `2026-09-07, версия 1`

## Цель

Переработать личный кабинет и сайт donbilet.ru согласно пп. 2.1–2.26 и 3.1–3.5 ТЗ,
переведя платформу с legacy-стека (iDempiere 7.1 + Angular 8) на целевую архитектуру
Next.js 16 + NestJS + PostgreSQL согласно
[`docs/plan-tz/DonBilet — технологический стек и целевая архитектура.md`](../docs/plan-tz/DonBilet%20—%20технологический%20стек%20и%20целевая%20архитектура.md).

## Границы

### В scope

- 26 функциональных пунктов раздела 2 ТЗ.
- 5 технических требований раздела 3 ТЗ.
- Вывод iDempiere из эксплуатации (трек B) — **при условии подтверждения Q2**.

### Вне scope

- Пп. 4.1–4.9 ТЗ (изменения мобильного приложения, ИИ в поддержке, кошелёк, ЛК юрлиц,
  сохранение карт, графическая схема мест в боте, публичные отзывы, динамическое
  ценообразование, рейсы с пересадкой).
- Интеграция с 1С — в ТЗ Приложения № 1 отсутствует, требует решения (Q4).
- ЖКХ-домен `personalaccount` — требует решения (Q3).

## Критерии приёмки по фазам

Приёмка по п. 5.2 ТЗ — **по каждому пункту раздела 2 отдельно**.

Общий Definition of Done для каждой фазы:

- [ ] Функциональность соответствует описанию пунктов ТЗ в объёме фазы
- [ ] `bun run build:all` в `backend/` без ошибок
- [ ] `bun run lint` в `backend/` и `frontend/` без ошибок
- [ ] Миграции применены; для новых tenant-таблиц — RLS-блок и запись в `model-ownership.yml`
- [ ] `bun run test:rls` проходит
- [ ] `npm run smoke` проходит
- [ ] Playwright-сценарии фазы проходят
- [ ] Отчёт в `audit/reports/` с воспроизводимыми evidence
- [ ] `audit/CURRENT.md` обновлён

Дополнительные критерии по фазам — в [`docs/plan-tz/roadmap.md`](../docs/plan-tz/roadmap.md).
