# ROADMAP

Этот файл хранит только утверждённый план реализации. Он отвечает на вопрос
«что и в каком порядке должно быть сделано», но не доказывает фактическую готовность.
Развёрнутое обоснование фаз, оценки, риски и матрица покрытия — в
[`docs/plan-tz/roadmap.md`](../docs/plan-tz/roadmap.md).

## Метаданные

- Статус: `approved`
- Версия: `2`
- Утверждено: `2026-09-07`
- Владелец: `ИП Спиркин И.Р.`
- Источник ТЗ: `Приложение № 1 к Договору №4063 от 10.08.2026` — [`docs/plan-tz/tz.md`](../docs/plan-tz/tz.md)
- Последнее изменение scope: `2026-09-07, версия 2 — отказ от переноса legacy`

## Цель

Переработать личный кабинет и сайт donbilet.ru согласно пп. 2.1–2.26 и 3.1–3.5 ТЗ.
Новый фронтенд создаётся **с нуля по макету**, данные берутся из **действующего API
DonBilet** — контракт зафиксирован в [`docs/plan-tz/api-donbilet-v2.md`](../docs/plan-tz/api-donbilet-v2.md).

## Границы

### В scope

- 26 функциональных пунктов раздела 2 ТЗ (с оговоркой по Q8, см. ниже).
- Технические требования 3.2–3.5.
- Собственный backend только под функциональность, отсутствующую в API DonBilet.

### Вне scope

- **Перенос legacy-кода.** Ни Angular-компоненты, ни Java-модули не переносятся.
- **Переписывание backend DonBilet**: интеграции с перевозчиками, booking,
  ticketing, payment, фискализация остаются как есть.
- **Вывод iDempiere из эксплуатации** — отдельный проект за рамками договора №4063.
- Пп. 4.1–4.9 ТЗ.
- П. 3.1 (консолидация дублирующих модулей) — работа в чужом коде, вопрос Q9.

## Критерии приёмки

Приёмка по п. 5.2 ТЗ — **по каждому пункту раздела 2 отдельно**.

Общий Definition of Done фазы:

- [ ] Функциональность соответствует описанию пунктов ТЗ в объёме фазы
- [ ] `bun run build:all`, `bun run lint` без ошибок; `tsc --noEmit` на фронте чист
- [ ] Миграции применены; новые tenant-таблицы имеют RLS и запись в `model-ownership.yml`
- [ ] `bun run test:rls` и `npm run smoke` проходят
- [ ] Playwright-сценарии фазы проходят
- [ ] Отчёт в `audit/reports/` с воспроизводимыми evidence
- [ ] `audit/CURRENT.md` обновлён
