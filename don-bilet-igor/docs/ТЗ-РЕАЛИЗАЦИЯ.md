### Флоу покупки (сделано, кнопка «Купить» в результатах → `/buy`)
| Шаг | Модуль | Статус |
|---|---|---|
| start/ticket — создание заказа, бронь 20 мин (таймер в UI) | `api/purchase/start` | ✅ |
| getpass — сводка заказа, цены, страховка, типы документов, схема мест | `api/purchase/order` | ✅ |
| ctzn — справочник гражданств | `api/purchase/citizenships` | ✅ |
| Форма пассажиров + выбор места (type 1=свободно, 2=занято, 0=проход) | `components/buy/BuyFlow.tsx` | ✅ |
| Страховка отдельным блоком (ТЗ п.11) | `BuyFlow` | ✅ |
| **Реальные чекбоксы согласия** (в старом коде было захардкожено true) | `BuyFlow` + `api/purchase/passengers` | ✅ |
| addpasslog + addpass — сохранение пассажиров | `api/purchase/passengers` | ✅ (код готов) |
| buy — handoff на Payler (реальный платёжный URL) | `api/purchase/buy` | ✅ |

**Проверено вживую:** search → start → getpass → ctzn → buy работают, `buy` возвращает реальный
URL оплаты Payler. **Ограничение боевого бэка:** онлайн-бронь сейчас отключена на ВСЕХ рейсах
(из 232 просмотренных рейсов в разных направлениях/датах `isBook="Y"` — 0), поэтому `addpass`
отвечает 422 «не удалось зарезервировать». Флоу построен верно; завершить оплату можно, когда
Заказчик включит бронь (`isBook=Y`) хотя бы на одном рейсе или даст тестовый контур.
Оплату (списание) не проводим — только handoff на Payler.
