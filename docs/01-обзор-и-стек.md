## 1.5. Схема развёртывания

```
                       Браузер / мобильное приложение
                                   │
                    ┌──────────────┴──────────────┐
                    │                             │
         Node.js (Express, порт 4000)      прямые вызовы API
         Angular Universal SSR             (мобильные клиенты)
         pm2 → dist/server.js                     │
                    │                             │
                    │ HTTPS: https://donbilet.ru/WSv2 ← alias
                    └──────────────┬──────────────┘
                                   ▼
              iDempiere (OSGi/Equinox, встроенный Jetty)
              ├── бандл ru.siberium.donbilet.webservices  → /DBInterface/services/donbilet/V2
              ├── бандл ru.siberium.personalaccount       → /SIBInterface/services/barnaul
              ├── бандл ru.siberium.models      (ModelFactory, SCR-компонент)
              ├── бандл ru.siberium.processes   (SvrProcess, планировщик iDempiere)
              └── бандл ru.siberium.callouts    (CalloutFactory)
                                   │
              ┌────────────────────┼─────────────────────┐
              ▼                    ▼                     ▼
        БД iDempiere        API перевозчиков       Эквайринг + ФНС
     (таблицы sib_*)        (12 провайдеров)   (Сбербанк, Альфа, Payler)
```

Публичный путь `https://donbilet.ru/WSv2` (значение `apiEndpoint` в `environment.prod.ts`) — это реверс-прокси на `/DBInterface/services/donbilet/V2`, что видно из `environment.testEnv.ts`, где указан прямой адрес `http://localhost:8080/DBInterface/services/donbilet/V2`.

## 1.6. Команды сборки

**Backend** — Maven Tycho в составе сборки iDempiere (`packaging: eclipse-plugin`), затем деплой бандлов в `plugins/` целевой платформы. Отдельного CI/скриптов деплоя в репозитории нет.

**Frontend** (`Makefile` + `package.json`):

```bash
npm start                 # ng serve, дев-режим
make build                # ng build (NODE_OPTIONS=--max-old-space-size=4096)
make build-prod           # npm run build:ssrProd + tar/gzip в builds-prod/
make build-test           # сборка testEnv + pm2 restart dist/server.js
npm run serve:ssr         # node dist/server
```

Сборка требует 4 ГБ heap для Node — признак разросшегося бандла. Артефакты продакшена версионируются вручную tar-архивами с датой в имени (`dist-20220415.tar`) — последняя дата в `Makefile` указывает на апрель 2022 как ориентир последнего релиза.
