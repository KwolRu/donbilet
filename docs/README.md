# Документация по старому проекту DonBilet

Результат реверс-инжиниринга кодовой базы `01_СТАРЫЙ_ПРОЕКТ`.
Дата анализа: 2026-09-07. Анализ проведён по исходникам, без запуска системы.

## Что за проект

DonBilet — онлайн-продажа билетов на междугородние автобусы (регион Ростов-на-Дону / Дон).
Система состоит из двух независимо разворачиваемых частей:

| Часть | Расположение | Стек |
|---|---|---|
| Backend | `extracted/db_new-master/db_new-master/` | Java 11, OSGi-плагины к ERP **iDempiere 7.1**, Apache CXF (JAX-RS), Spring 3.0, PostgreSQL/Oracle через iDempiere |
| Frontend | `extracted/donbilet-front-master/donbilet-front-master/` | **Angular 8.2** + Angular Universal (SSR на Express), TypeScript 3.4, SCSS, Angular Material 8, Bootstrap 4 |

## Краткий вывод

Это legacy-система 2019–2022 годов на снятых с поддержки версиях (Angular 8 — EOL с 2020, iDempiere 7.1, Spring 3.0.7 — 2011 год, Apache CXF 2.6 — 2012 год, Axis 1.x).
Бизнес-логика полностью погружена в ERP iDempiere: REST-слой — это тонкие плагины поверх модели iDempiere, а «сервисы» напрямую ходят в БД и во внешние API перевозчиков.

Основные архитектурные проблемы: дублирование целого модуля (`personalaccount` — форк-предок `donbilet.webservices`), 4279 строк в одном классе `ReserveService`, отсутствие DTO-слоя (ответы — `List<Map<String,Object>>`), 171 JAR-файл в git, секреты в репозитории, MD5 для паролей, SQL-конкатенация. Детали — в [07-риски-и-техдолг.md](07-риски-и-техдолг.md).
