## Обязательные проверки по типу задачи

Отметить применимые; неприменимые — вычеркнуть с обоснованием.

- [ ] **Абстракция/адаптер:** работает на **двух** реализациях; переключение — конфигом;
      `git diff --stat` по бизнес-коду пуст.
- [ ] **Tenant-изоляция:** запрос под тенантом A к сущности B → 404/403; подстановка
      чужого tenant-заголовка не меняет результат; **пустой тенант видит пустые списки**.
- [ ] **Идемпотентность:** повтор с тем же ключом → тот же результат, побочный эффект не
      повторился.
- [ ] **Durable-процесс:** воркер убит посередине → процесс продолжился с того же шага.
- [ ] **Политика:** `opa test` зелёный; живой отказ содержит внятную причину; недоступность
      движка → отказ (fail-closed).
- [ ] **Лимит/бюджет:** при исчерпании **новых выполнений не появляется**; код ответа 402/429.
- [ ] **Секреты:** сервис не стартует без обязательного секрета; в репозитории значений нет.
- [ ] **AI-задача:** golden-датасет зелёный, live-прогон сохранён (см. `ai-evals-ops`).
- [ ] **Контракт:** неподдержанная версия отклоняется явно; ошибки классифицированы.
